# M1 — API stubs, determinism core, pattern strategies

Ordered checklist; the order is load-bearing (stubs freeze the API before implementation;
vectors freeze the algorithms before anything consumes them). Spec references are to
`SPECIFICATION.md`. Package root: `io.github.dconneely.alterego`.

**Reference salt** for all golden/vector tests: the UTF-8 bytes of
`"alterego-reference-salt!"` (24 bytes). Never change it.

- [x] **1. Public API stubs** — every type below, fully Javadoc'd from the spec, compiling,
  method bodies `throw new UnsupportedOperationException("M<n>")` where not yet implemented.
  - Root package: `Strategy` (§2.1), `TransformationContext` (§2.2), `Mappings` (§2.3),
    `Randomness` (§2.4), `Transformation` (§2.5), `AlterEgo` + `AlterEgo.Builder` (§2.6),
    `NullPolicy` (§2.5), `RecordScope` (§6.1), `AttributeKey` and `RecordAttributes` (§6.2),
    `AlterEgoAttributes` and `UkNation` (§6.3).
  - Exceptions (§8): `AlterEgoException`, `AlterEgoConfigException`,
    `AlterEgoPatternException extends AlterEgoConfigException`, `AlterEgoStoreException`,
    `AlterEgoCollisionException`, `AlterEgoCoherenceException`.
  - `store` package (§5.1): `MappingStore` with nested sealed `PutUniqueResult`
    (`Stored`, `ExistingMapping`, `ValueTaken`); `InMemoryMappingStore` stub.
  - Restore the module exports M0 deferred (see `docs/tasks/M0.md`): add
    `exports io.github.dconneely.alterego;` and `exports io.github.dconneely.alterego.store;`
    to `module-info.java` now that both packages hold public types.
  - Acceptance: `./gradlew build` green; no public member lacks Javadoc.

- [x] **2. Appendix A implementation** (package-private, root package)
  - `Derivation` — A.1 message layout and HMAC-SHA256 via `javax.crypto.Mac`; all three purpose
    constants `alterego/1/random`, `alterego/1/mapkey`, and `alterego/1/record` (the last is
    consumed in M5, but the derivation and its vectors land here); 4-byte big-endian counter;
    `char[]` salt via UTF-8.
  - `HmacRandomness implements Randomness` — A.2 counter-mode block stream (lazy, 32 bytes per
    block) and A.3 primitives exactly as written (63-bit rejection sampling for `nextLong`;
    `nextBoolean()` = `nextLong(2) == 1`; `pick`/`digit`/`letterUpper`/`letterLower`).
  - Guard behaviour: `nextInt`/`nextLong` with `bound <= 0` and `pick` with an empty list throw
    `IllegalArgumentException`.
  - Acceptance: `./gradlew test --tests '*Randomness*' --tests '*Derivation*'` green (unit tests
    for guards and basic stream behaviour; exact values come in step 3).

- [x] **3. Conformance vectors** — generate, independently review, freeze.
  - A generator in test sources (e.g. `VectorGenerator` with a `main`), writing JSON to
    `src/test/resources/vectors/`:
    - `derivation.json` — (salt, purpose, domain, canonical, counter) → key as 64 lowercase hex,
      ≥ 12 cases covering all three purpose tags and including counter > 0, empty canonical,
      canonical containing `0x00`, and non-ASCII canonical.
    - `stream.json` — key → first 96 stream bytes (hex), ≥ 4 cases.
    - `sampling.json` — key + ordered call list (`nextInt(10)`, `pick(size=5)`, `digit`, ...) →
      results, ≥ 8 cases including a `nextLong` bound that forces rejection.
    - `mapkey.json` — (salt, domain, canonical) → 64-hex store key (A.4), ≥ 6 cases.
  - **Independent review gate**: independently recompute at least three `derivation.json` keys outside
    the JVM (e.g. Python `hmac` over the exact message bytes) and confirm they match. Do not
    skip; do not proceed until confirmed. `tools/verify_vectors.py` is the standalone script that
    backed this gate — a from-scratch Python reimplementation of Appendix A, checked against
    every case in all four vector files, not just the required three. Re-run it
    (`python3 tools/verify_vectors.py`) any time the frozen vectors need a second opinion, or
    adapt it as the starting point for a future major version's review gate.
  - `ConformanceTest` loads every vector file and asserts all cases.
  - From this point the vector files are frozen.
  - Acceptance: `./gradlew test --tests '*ConformanceTest*'` green.

- [x] **4. Context and Mappings**
  - `TransformationContext` implementation created per input by the binding machinery;
    `derived(subDomain, subInput)` performs a fresh A.1 derivation, counter 0.
  - `Mappings` view: domain-scoped, hashes keys per A.4 before touching the `MappingStore`;
    throws `AlterEgoStoreException` when no store is configured.
  - Outside-scope `record()` no-op per §6.2: `get` empty, `set` discarded, `computeIfAbsent`
    resolves (with the asking strategy's `Randomness`) without retaining. Scoped behaviour
    lands in M5.
  - Invariant test: for the same domain/input, `derived(...)` yields a `Randomness` producing an
    identical stream to a top-level context (§2.2 invariant).
  - Acceptance: invariant test and no-op `record()` tests green.

- [x] **5. Value-type registry** (package-private `ValueCodecs`)
  - Canonical encode/decode for the §2.6 set: `String`, `Integer`, `Long`, `Boolean`,
    `LocalDate`, `LocalDateTime`, `Instant`, `UUID`, enums (via `Class::isEnum`).
  - Round-trip tests, including `LocalDateTime` with zero seconds and with nanoseconds.
  - Unsupported type → `AlterEgoConfigException` naming the type and listing the supported set.
  - Acceptance: registry tests green.

- [x] **6. AlterEgo builder and binding**
  - Builder: salt required and ≥ 16 bytes (reject with `AlterEgoConfigException`); locale
    defaulting to the fixed constant `Locale.UK` (ADR 0006 — `Locale.getDefault()` is banned);
    optional `MappingStore`; `NullPolicy` default `PASS_THROUGH`. No `Clock` — the library never
    reads time (ADR 0007).
  - `bind(domain, strategy)` / `bind(domain, type, strategy)`: domain validated against
    `[A-Za-z0-9:._-]{1,100}`; returns an immutable `Transformation` that canonicalises the
    input, derives the context, applies the strategy, honours `NullPolicy`.
  - Decorator algebra (§2.5): `unique()` and `stored()` are idempotent, `unique()` subsumes
    `stored()`; both throw `AlterEgoStoreException` (store not configured / not yet implemented
    — full behaviour lands in M4).
  - Acceptance: builder validation tests and a `bind`-based end-to-end determinism test green.

- [x] **7. Pattern strategies**
  - `pattern` package: compiler for `D`, `L`, `l`, `A`, `\` escape, literals (§4.6); malformed
    pattern (e.g. trailing `\`) → `AlterEgoPatternException` with the offending position;
    compiled at `pattern(...)` call time.
  - Factory methods on `AlterEgo`: `pattern(String)`, `constant(T)`, `mask(char, int)` (§4.7:
    short input unchanged, negative `keepLast` → `AlterEgoConfigException`). There is no
    `formatPreserving()` — format inference is a non-goal (§1).
  - Acceptance: pattern unit tests green, including token `A`'s 52-way mapping per A.3.

- [x] **8. Milestone test gates**
  - Property tests (jqwik): for `pattern`, `t.apply(x)` is stable across repeated calls,
    input-order permutations, and sequential vs parallel streams.
  - `GoldenOutputsTest`: exact expected outputs for the reference salt across the M1
    transformations; values generated once, eyeballed for plausibility, then frozen.
  - Acceptance: `./gradlew build` green; all M1 "done when" criteria in `PLAN.md` met.
    *(verified: 74 tests green across a clean build; see M1 completion note below.)*
