# M8 — Identifier built-ins

Read first: `SPECIFICATION.md` section 4.8 (the contract), Appendix A.5-A.9 (the exact
algorithms — draws happen in exactly the order written there), section 4.1 (the guarantee
table), and `docs/adr/0012-identifier-builtins-fictional-spaces.md`. Do not deviate; if you find
a gap, stop and flag it — do not invent behaviour.

Hard rules for this milestone:

- No existing golden output, conformance vector, or Appendix A.1-A.4 algorithm may change. If
  any existing test's expected value would change, stop and flag it.
- New golden values are **computed, never guessed**: use the temporary-printer procedure below.
- The five domain strings in spec 4.8 are frozen the moment they ship — copy them exactly.
- There are no options types and no `realistic()` variants for these five (ADR 0012). Do not add
  any.
